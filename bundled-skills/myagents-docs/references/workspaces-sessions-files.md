# Workspace、Session 与本地工作面

## 四个核心概念

| 概念 | 用户视角 |
|---|---|
| Workspace | Agent 工作的真实文件目录和项目上下文 |
| Agent | 围绕一个 Workspace 配置的 AI 身份与能力集合 |
| Session | 可持续恢复的对话和执行身份，保存历史与当前 Runtime 等状态 |
| Tab | 主窗口里查看和操作 Session 的界面容器；多个 Tab 可并行工作 |

同一个 Workspace 可以有多个 Session。Session 不等于某个 Tab：历史 Session 可以重新打开，后台 Task、Goal 或 Channel 也可能在没有可见 Tab 时继续使用它。

## 从工作区开始

在 Launcher 选择或创建工作区后，MyAgents 会把 Chat、文件树、Skills、命令、终端和历史围绕这个目录组织起来。适合把长期项目、写作目录、代码仓库或个人知识库分别作为不同 Workspace。

Workspace 决定很多能力的作用域：

- `@` 文件和本地图片从哪里解析
- Agent 默认模型、Runtime、权限与工具配置
- 项目级 Skills 和 MCP 启用状态
- Task 和定时自动化针对哪个工作目录执行
- Session 历史属于哪个工作上下文

不要把两个不同路径只因名字相同就当成一个 Workspace；移动或重命名目录后，必要时通过产品入口重新确认绑定。

## 多 Tab 与 Session

- 每个 Chat Tab 绑定自己的当前 Session，不同 Tab 的消息、流式状态和工具调用应彼此隔离。
- 打开已有 Session 时，MyAgents 会恢复持久历史和对应 Runtime 身份。
- 如果目标 Session 已在另一个 Tab 打开，产品可能直接跳到该 Tab，避免两个 Tab 同时控制同一 Session。
- 切换到后台 Task、Goal 或 Channel 正在使用的 Session 时，应采纳该 Session 的现场配置，而不是用当前 Tab 的选择覆盖它。
- 关闭 Tab 通常只关闭桌面入口；是否停止后台执行取决于该 Session 是否仍被 Task、Goal、Channel 等使用。

### 历史、回溯与分叉

- 历史 Session 是持久数据，可从 Launcher 或历史列表恢复。
- 回溯用于回到较早的对话点；如果某轮没有文件 checkpoint，仍可能只回溯消息而没有文件变化可恢复。
- 分叉适合从某个历史点开始新的方向，避免把两条工作线混在同一 Session。
- 自动化 Session 可以在历史列表中单独显示或收起，避免周期任务刷屏。

## 工作区文件能力

MyAgents 的文件树与文件操作属于桌面应用能力，不依赖某个 AI Runtime 已经启动。因此 Launcher 和 Chat 都应能使用同一套文件能力。

用户可以：

- 浏览目录树、懒加载子目录
- 预览文本、Markdown、图片和支持的文档类型
- 新建、重命名、移动、复制和删除文件/目录
- 把外部文件拖入工作区
- 使用 `@` 引用文件或图片给 Agent
- 在 Finder/资源管理器或默认应用中打开文件
- 监听文件变化并刷新树

删除通常优先进入系统回收站；永久删除、覆盖或移动前应确认具体对象。

### 文件安全与限制

- 读文件会解析真实路径并阻止 symlink 越过工作区；写入允许目标尚不存在，但仍受工作区边界约束。
- 预览、附件和传输都有大小与文件类型限制。文件太大时应下载/打开或让 Agent按普通文件处理，而不是强行塞进消息。
- `myagents_files/` 是 Agent 产物与需要稳定引用的工作区目录之一；大文件应作为文件或附件处理，不要把完整编码内容贴进聊天或 Issue。
- 用户数据目录、凭据目录和系统敏感路径不会因为“打开文件”请求自动解除保护。

## 本地全文搜索

MyAgents 支持两类搜索：

- 跨工作区搜索 Session 历史
- 搜索当前 Workspace 的文件名与文件内容

中文内容会使用中文分词。搜索索引是本地派生数据；源会话或文件仍是权威。如果刚写入的内容暂时没出现，可以等待索引刷新；持续缺失才进入 support。

## 内嵌终端

终端绑定当前工作区，适合运行项目命令、观察日志和验证 Agent 改动。它是独立的交互式终端，不是聊天工具调用的替代品；关闭终端面板不一定立即停止其中的进程，关闭对应工作入口或应用时会统一清理。

MyAgents 会把内置运行环境和自身 CLI 放进终端，但仍尽量尊重用户已有 shell 与工具环境。终端里可用不代表外部 Runtime 看到的环境完全相同，遇到差异要用 Runtime 诊断确认。

## 内嵌浏览器

浏览器用于在工作区旁预览网页、Agent 链接和本地 HTML。网页内容与桌面应用权限隔离，不能直接获得 MyAgents 的本地权限。关闭浏览器页会结束该页面；登录 cookie 可以在应用浏览器中保留。

## 工具产物与附件

Agent 生成的图片、音频、PDF 等使用统一附件形式展示。用户通常会看到工具卡后的媒体画廊，并可在工作区 `myagents_files/` 找到部分产物。附件属于产生它的 Session；切换或恢复 Session 后仍应重新可见。

## 什么时候应转入 support

- 文件树在 Launcher 失败但 Chat 正常，或反过来
- 同一 Session 的消息出现在错误 Tab
- 历史恢复丢失最新内容、回溯覆盖了错误会话
- `@` 合法工作区文件稳定失败
- 文件已经生成并存在，但 Tool Attachment 不显示
- 终端正常、同一命令在 Agent Runtime 环境却稳定失败
