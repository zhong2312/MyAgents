# 通用叙事设计与灵感工作面 v1 设计任务书

## 目标

为 MyAgents 小说工作台设计一套面向所有小说类型的可点击原型，验证“通用叙事工程内核 -> 创作配置包 -> 项目规则 -> 作者调整”如何转化为清晰、低摩擦的作者工作面。

本轮只产出 Open Design 原型，不修改 `src/` 产品源码。必须创建新的 `narrative-studio-v1/`，不得修改或删除已有物品库、设定库设计产物。

## 核心原则

- 日常创作界面只展示作者语言，例如剧情线、故事弧、章节计划、伏笔、灵感；不展示 `core.thread` 等技术 ID。
- 底层不能硬编码仙侠、网文或《仙途》概念。卷、副本、爽点、商业节点、奇则碰撞和章节六项交付均来自配置包或项目规则。
- 配置包只定义字段、关系、校验、术语和视图，不注入可执行代码或新 UI 组件。
- 计划、实际事实、素材和派生结果必须在界面语义上可区分。
- 原型用于高频编辑，不做营销页、统计大屏或卡片仪表盘。

## 信息架构

小说工作台左侧一级导航新增：

1. `叙事设计`：原“大纲”升级后的结构化剧情工程工作面。
2. `灵感`：项目级灵感收集、整理和采用追踪。
3. `创作方案`：管理当前项目启用的篇幅、载体、发布方式、题材、创作方法与项目规则。

保留原有 `outline.md` 自由大纲入口，在叙事设计中作为“自由大纲”视图，不把 Markdown 编辑能力删除。

## 通用对象

原型需要体现但不直接暴露以下统一能力：

- 结构单元：部、卷、幕、案件、人生阶段、章节组。
- 叙事线路：主线、支线、人物线、关系线、调查线、主题线。
- 故事弧：有起点、发展、转变和终点的状态变化。
- 叙事节点：场景、节拍、转折、信息揭示、章节节点。
- 期待：承诺、悬念、谜团、伏笔、预言及其兑现。
- 情境：条件、行动、代价、结果组成的结构模块。
- 检查项：可挂载到卷、章节、线路、故事弧或其它对象的验收规则。
- 灵感：片段、意象、问题、场景、人物火花或研究触发点。

## 示例项目

主示例使用《仙途》，当前创作方案由以下层次组成：

```text
通用叙事内核
-> 长篇小说
-> 连载创作
-> 东方玄幻
-> 《仙途》项目规则
-> 作者本地调整
```

《仙途》的作者术语可以显示为主线/暗线、卷/单元/副本、爽点、商业节点、奇则碰撞、章节六项交付和卷级验收，但创作方案页面必须清楚表明这些是配置实例。

创作方案页面还需提供一个“悬疑长篇”预览示例，展示同一套工作面可改为案件、调查线、线索、谜团、公平性检查，不创建另一套产品模块。

## 工作面一：叙事设计

桌面 1440x900 使用连续三栏布局：

1. 左栏约 240px：故事结构树。显示卷、单元和章节组，支持折叠；顶部可切换“结构 / 对象筛选”。
2. 中栏占主要宽度：根据当前视图显示线路泳道、章节计划表、期待追踪、检查结果或自由大纲。
3. 右栏约 320px：选中对象详情与关系。显示摘要、状态、字段、关联线路、章节锚点、检查项和来源灵感。

页头提供：当前项目方案、视图切换、搜索、筛选、校验摘要、加号新建命令。

必须可切换的视图：

- 线路：横轴为结构/章节，纵轴为主线、支线、人物线等；节点可点击，连接关系清楚但不过度装饰。
- 故事弧：按状态或阶段组织，展示起点、关键转变、终点和涉及角色。
- 章节计划：密集表格，列出章节目标、关键节拍、关联线路、期待、结果维度和完成情况。
- 期待追踪：展示建立、强化、兑现、失效；伏笔只是当前项目采用的期待类型。
- 验收：按内核、配置包、项目规则分组展示错误、警告、建议及修复入口。
- 自由大纲：页面级 Markdown 编辑器。

必须演示：

1. 在线路视图选择“丹成大道”节点，右侧显示它属于主线、关联第 42 章、包含一个奇则碰撞情境和两个待兑现期待。
2. 切换到章节计划，打开第 42 章，查看六项交付和来源线路；六项交付需标明来自《仙途》项目规则。
3. 切换到期待追踪，查看伏笔“灰烬中的第二道剑痕”的埋设、强化和计划回收。
4. 打开验收视图，看到一条通用引用错误、一条连载节奏警告和一条《仙途》卷级验收问题。
5. 从任意对象打开“关系”区域，区分计划锚点与已经发生的时间线事件。

## 工作面二：灵感

桌面使用三栏：

1. 左栏：收集箱、待整理、已采用、未采用、已归档、标签与来源。
2. 中栏：灵感列表，可搜索、筛选、按更新时间/来源/采用状态排序；支持列表和看板视图。
3. 右栏：灵感正文、类型字段、来源、标签、关联对象和采用记录。

必须演示：

1. 选中“倒着生长的灵根”，显示它仍在待整理状态。
2. 点击“采用为”，选择“情境 -> 奇则碰撞”，关联到“丹成大道”，预览将创建的关系。
3. 确认后，灵感自动进入“已采用”投影并显示采用去向；不得要求作者额外勾选“已采用”。
4. 同一灵感可继续采用为场景、期待或世界设定，不限制一对一。
5. 显示“来自 MyAgents 想法”的临时来源，但明确项目灵感已复制为项目事实，不依赖全局 Thought 存储。

## 工作面三：创作方案

采用左侧方案层级、中央定义列表、右侧影响预览的连续工作面：

- 左侧显示内核、长篇、连载、东方玄幻、《仙途》规则、作者调整六层来源及启用状态。
- 中央按“术语、对象类型、字段、关系、检查项、视图”查看解析后的定义。
- 右侧展示当前选择影响到哪些工作面和已有数据。
- 直接重复的稳定定义 ID 必须以阻断冲突展示；合法覆盖必须显示显式来源和被覆盖项。
- 提供“悬疑长篇预览”按钮，临时展示案件/调查线/线索矩阵和公平性检查的术语变化，但不得修改《仙途》正式配置。

## 状态覆盖

- 正常有数据、首次空项目、搜索无结果、加载中。
- 保存中、已保存、保存失败和外部修改冲突。
- 配置包冲突阻断、引用失效、校验警告、手工豁免及豁免原因。
- 未保存时切换对象确认。
- 超长标题、超长术语和大量标签不得溢出。

## 响应式

- 1440x900：完整三栏高频编辑。
- 1024x768：右侧详情可折叠，结构栏保留。
- 390x844：列表/画布/详情分步导航；结构与筛选使用抽屉；关系图和线路图允许受控横向平移，但整个页面不得横向溢出。

## 视觉与组件约束

- 遵循 MyAgents 暖纸设计系统：`#faf6ee`、`#fffcf7`、`#e8dccf`、`#1c1612`、`#6f6156`、`#c26d3a`、`#2e6f5e`。
- 正文 16px、常规 UI 14px、元信息 12px；字间距为 0，不随视口缩放字体。
- 工作面安静、密集、可扫描。页面分区使用连续面和分隔线，不使用卡片套卡片。
- 卡片圆角不超过 8px；不用渐变、光斑、装饰插画或营销式大标题。
- 图标使用 Lucide；熟悉命令优先使用图标按钮并提供 title/aria-label。
- 线路/关系画布参考 React Flow，排序参考 dnd-kit，表格参考 TanStack Table，但原型不得加载不受控的远程脚本。

## 交付要求

- 生成 `narrative-studio-v1/index.html` 作为主入口，可拆分同目录 CSS/JS。
- 更新 Open Design 项目根 `index.html` 指向本轮入口，但不得修改旧设计目录。
- 所有文案使用中文，必须有真实可点击交互，不能只输出静态截图或说明文档。
- 生成桌面 1440x900 与移动 390x844 的实际渲染预览图。

## 验收标准

- 第一眼能区分结构、线路/计划、当前对象详情三个层级。
- 第一眼能理解《仙途》术语来自项目方案，而不是工作台硬编码。
- 叙事设计、灵感和创作方案之间能双向跳转并保留上下文。
- 灵感“已采用”由关系推导，采用去向可追溯。
- 同一套界面通过悬疑预览能自然转换术语和校验，不出现仙侠残留。
- 桌面与移动端均无文字遮挡、控件溢出和不可到达操作。
