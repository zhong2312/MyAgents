## P0 · 阻断：整页 JavaScript 未执行

- 证据：在 Edge/Playwright 加载 `narrative-studio-v1/index.html` 后，Node `new Function(inlineScript)` 返回 `SyntaxError: Unexpected token 'function'`。
- 根因：`renderSchemeInspector()` 的 `else` 分支后多出一个 `}`，导致后续 `function toggleMystery` 无法解析。
