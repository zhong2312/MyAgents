# 世界推演 V4 工作台原型

## 目标

为 MyAgents 小说工作台设计新版“世界推演”可点击原型，验证作者可以完成：创建推演设置、进入某次推演运行、按固定时间跨度推演一轮或连续多轮、回看历史轮次，并同时理解该轮发生的事件和该时间点的世界状态。

本轮只产出 Open Design 原型和预览图，不修改 `src/` 产品源码。旧的“运行控制台 / 世界实验室 / 立场会商”三工作面不得出现在新版信息架构中。

## 已确定的产品决策

- 世界推演位于小说工作台“辅助”二级菜单；进入模块直接打开新版界面。
- 不兼容旧 V3 世界推演数据、页面或存储。后续实现会删除无用旧代码，不设计迁移或兼容提示。
- 一次运行由“总推演范围”和“每轮时间跨度”共同定义。每一轮是作者可见、可持久化、可回看的单位。
- 创建推演后不自动开始。作者进入工作台后明确点击“推演 1 轮”。
- 连续推演允许输入轮数 N，逐轮完成、逐轮持久化；支持暂停、继续和取消。
- 历史轮次显示该轮结束时间点的实体状态；从已完成轮次可以创建分支。

## 核心流程

```text
辅助 > 世界推演
→ 新建推演
→ 填写设置并创建运行
→ 点击“进入推演”
→ 推演 1 轮 / 连续推演 N 轮 / 推演至终点
→ 选择历史轮次，查看事件与世界状态
```

## 原型范围

必须提供同一原型中的可点击状态，而不是只做一张静态页面：

1. `推演列表与创建设置`
   - 左侧为“推演运行”列表，选中“北境灵脉演化”。
   - 右侧为新建推演设置，分区包括：名称、事实截止点、总推演范围、每轮时间跨度、范围与主体、剧情约束、智能模式和预算。
   - 重点字段示例：总范围“十二年”，每轮跨度“三个月”。
   - 显示紧凑的基线检查结果。点击“创建推演”后进入该运行的概览，再点击“进入推演”进入工作台。

2. `三栏推演工作台`
   - 顶栏：推演名称、当前分支、当前世界时间、第 7 轮、运行状态；右侧放“推演 1 轮”主按钮、“连续推演”数量控件、暂停、更多操作。
   - 左栏固定约 260px，为纵向时间线。包括“第 0 轮 事实基线”和第 1 至第 8 轮；每行显示时间范围、事件数量、完成/暂停/告警状态。第 7 轮为选中状态。
   - 中栏为“舞台”，展示选中第 7 轮的事件发生过程。按顺序呈现人物行动、势力策略、冲突、传播和世界过程；每项显示时间、主体、地点、简要结果和状态变化。选中一条“北山封印破裂”的事件。
   - 右栏固定约 340px，为“当前时间点”检查器。显示选中轮次结束时刻；页签为人物、势力、地域、物品、世界。默认打开人物，展示主角、守阵人、赤霄宗的地点、状态、意图、关系与资源摘要，并能切换到势力/地域。
   - 点击时间线轮次后，中栏事件范围和右栏时间点状态同步改变。点击中栏事件后，右栏自动定位关联人物或地域。

3. `连续推演与暂停状态`
   - 点击“连续推演”打开轻量浮层，输入“3 轮”，确认后显示正在推演第 8 轮的明确状态；时间线已完成轮次不能变化，正在执行轮次显示进行态。
   - 点击暂停后，保留前面已完成轮次，当前轮显示“暂停于模型候选裁定”。

4. `二级工具`
   - 分支、因果图、空间图、报告、会商和采纳不占主界面。它们从顶栏更多菜单或事件详情动作打开为抽屉/浮层。
   - 需要至少演示“从第 6 轮创建分支”和“查看本轮因果链”两个入口。

## 信息与样例

使用东方玄幻小说《沧澜纪》的可信样例，但界面不做封面或营销式叙事。轮次事件涉及：沈照夜、守阵人陆沉、赤霄宗、北山、灵脉、封印裂隙和山村传闻。数字、状态和告警只用作工作台信息，避免假装精确模拟。

## 视觉与交互约束

- 这是作者高频操作的桌面工作台，不是登陆页、数据大屏或卡片墙。
- 使用 MyAgents 现有暖纸主题与语义色：纸面、深墨、柔和暖棕主动作、绿色完成、蓝色信息、橙色警告、红色错误。不得使用渐变、光球、插画或大面积同色调铺底。
- 常规 UI 为 14px，元信息为 12px，正文为 16px；字间距为 0，不按视口缩放文字。
- 采用连续工作面、稳定分栏和细分隔线；不做卡片套卡片，圆角不超过 8px。
- 使用 Lucide 图标；熟悉操作优先用图标按钮，均有可见或悬停说明。
- 列表、时间线与状态面板必须适合高密度扫描；长标题截断但可查看完整内容。
- 原型内不出现解释产品功能或快捷键的说明性大段文字；空态必须给出具体动作。

## 响应式

- 1440 x 900：三栏完整常驻。
- 1024 x 768：保留左时间线与中舞台，右检查器可收为抽屉。
- 390 x 844：时间线、舞台、状态使用“轮次 / 舞台 / 状态”分步切换；全页不得横向溢出。

## 交付与验收

- 在项目中创建 `world-simulation-v4/index.html`，必要时拆分 CSS 和 JS；根入口指向该页面。
- 所有文案使用中文，并实现上述点击、切换、轮次选择和浮层交互。
- 生成桌面 1440 x 900、窄桌面 1024 x 768、移动 390 x 844 的真实预览图。
- 第一眼应看出“左侧时间、中央事件、右侧状态”属于同一轮次；不得再出现控制台、实验室、会商三级导航。
