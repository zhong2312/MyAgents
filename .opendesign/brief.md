# 小说设定库 v3 设计任务书

## 目标

重新设计 MyAgents 小说工作台设定库，采用单一空间层级作为全部设定的组织基础。作者自由设计空间树，但每个空间节点必须关联一个可配置的层级类型；层级类型通过项目内元配置决定默认出现哪些可填写的 Markdown 设定页面。

本轮必须生成新的 `setting-library-v3/` 原型，保留现有 `setting-library-v2/` 不变。

## 核心模型

```text
元配置
├─ 层级类型 LevelType
├─ 设定模板 SettingTemplate
└─ 类型模板方案 LevelTypeSettingProfile

空间节点 WorldNode
└─ 必须引用一个 LevelType
   └─ 显示该类型关联的默认设定模板
      └─ 作者可以继续添加当前节点自定义设定
```

不再使用“空间锚点 × 制度作用域”的双轴模型。每份设定直接归属于当前选中的空间节点。

## 元配置原则

- 层级类型可由作者创建、编辑、复制、归档和排序，不在代码中写死。
- 空间树的父子关系自由设计；类型只提供建议父类型和建议子类型，不做强制层级限制。
- 设定模板是页面级 Markdown 初始模板，可配置名称、分组、说明、Markdown 骨架和 Agent 引导。
- 类型模板方案负责把多个设定模板关联到一个层级类型，并配置顺序和默认启用状态。
- 类型关联的是默认模板，不是允许列表。任何层级、任何节点始终可以新增作者幻想世界需要的自定义设定。
- 默认设定采用惰性落盘：未填写时只在界面中显示虚拟页面，第一次编辑才创建 Markdown 文件。
- 元配置修改必须非破坏：新增关联会出现新的未填写页面；移除关联时已填写内容保留为节点自定义设定；修改模板不覆盖已有正文；切换节点类型不删除原内容。

## 示例数据

空间树示例：

```text
烬海世界根〔世界根〕
└─ 诸界域〔多元宇宙〕
   └─ 主宇宙〔宇宙〕
      └─ 苍衡星系群〔星系群〕
         └─ 青曜恒星系〔恒星系〕
            └─ 苍衡星〔星球〕
               └─ 九州大陆〔大陆〕
                  ├─ 大晟王朝〔国家〕
                  └─ 承天自由城〔独立城市〕
```

宇宙类型默认模板：宇宙总览、宇宙结构、时空规则、基础法则、文明分布、宏观势力、宇宙级重大事件。默认没有水系与山脉。

作者仍可在“主宇宙”节点新增“贯穿诸界的天河水系”，并选择：

- 仅添加到当前节点；
- 同时加入“宇宙”类型的默认模板方案。

国家类型默认模板：国家总览、疆域、政治、军事、经济、法律、社会、文化、宗教、民族、语言、日常生活。

## 主设定界面

采用三栏工作台，不使用卡片套卡片：

1. 左栏“空间层级”：自由空间树；每个节点持续显示层级类型标签；支持折叠、新增子节点、修改类型和自定义类型。
2. 中栏“当前节点设定”：根据节点类型分为“默认设定”和“自定义设定”；显示未填写、草稿、已完成状态；支持搜索、排序、新增设定。
3. 右栏“设定正文”：整个内容区是一个页面级可视化 Markdown 编辑器，包含常用格式工具、可视化/源码切换和保存状态。

顶部必须清楚显示：当前位置面包屑、当前节点名称、层级类型、进入元配置的入口。

去掉以下 v2 控件和概念：

- 空间锚点；
- 制度作用域；
- 跨宇宙多选；
- 继承、扩展、覆盖、替换；
- 冲突优先级和作用域冲突；
- 正文/词条/结构/关系四视图 Tab。

跨节点关系由后续知识图谱承担，不在本轮主编辑界面增加复杂作用域控件。地图仍是工作台左侧导航中的独立模块入口。

## 元配置界面

原型必须能从主设定界面进入元配置管理，并能返回原位置。元配置包含三个可切换页面：

### 层级类型

- 类型列表与使用节点数量；
- 编辑名称、说明、图标、地图表现类型；
- 配置建议父类型和建议子类型；
- 新建、复制、归档自定义类型；
- 显示“内置初始模板”与“项目自定义”来源，但项目副本都可以编辑。

### 设定模板

- 模板目录按世界、地理、政治、军事、经济、社会、文化等分组；
- 编辑模板名称、说明、Markdown 初始骨架和 Agent 引导；
- 新建模板、复制模板、预览模板；
- 模板版本变化不得覆盖已填写节点正文。

### 类型模板关联

- 选中某个层级类型后，配置默认关联的设定模板；
- 支持启用/停用、拖动排序和按分组筛选；
- 右侧即时预览“新建一个该类型节点时会出现哪些设定”；
- 明确提示“默认模板不是限制，节点仍可新增任意自定义设定”。

## 关键交互

- 新增空间节点时必须选择层级类型，也可在选择器内快速创建新类型。
- 修改节点类型时弹出非破坏性变更摘要：新增哪些默认页面，哪些已有页面将转为自定义，明确不会删除正文。
- 新增自定义设定时可以选择“仅当前节点”或“加入当前层级类型模板”。
- 在元配置中修改类型模板关联后，返回主界面能看到设定列表即时变化。
- 至少演示一个宇宙节点默认没有水系，但作者新增“天河水系”并可提升为宇宙类型默认模板的流程。

## 视觉语言

- 延续 MyAgents 安静、工作导向、高信息密度的暖纸视觉：背景 `#faf6ee`、抬升面 `#fffcf7`、下沉面 `#e8dccf`、正文 `#1c1612`、弱文本 `#6f6156`、暖橙强调 `#c26d3a`、冷绿辅助 `#2e6f5e`。
- 正文 16px、常规 UI 14px、元信息 12px；不随视口缩放字号，不使用负字距。
- 工作台导航默认收起；使用熟悉图标和工具提示；避免营销式构图、装饰渐变、大圆角和卡片堆叠。

## 响应式

- 桌面主视口 1440×900，三栏用于高频编辑。
- 390×844 时空间树和设定列表改为抽屉或分步导航，Markdown 编辑器保持独立工作面。
- 所有弹窗、选择器和菜单不能造成页面横向溢出或文字遮挡。

## 交付要求

- 生成 `setting-library-v3/index.html` 作为主入口，可拆分同目录 CSS/JS。
- 更新 Open Design 根目录 `index.html` 指向 v3，但不得修改或删除 v2。
- 原型必须有真实可点击交互，不能只输出说明文档。
- 所有界面文案使用中文。
- 完成桌面和移动端实际渲染检查，并生成 v3 预览图。

## 验收标准

- 用户第一眼理解所有设定都围绕空间节点组织，不再误解为“设定 × 空间”。
- 每个空间节点都能看到必选的层级类型。
- 层级类型、设定模板和二者关联都能配置。
- 默认模板只提供建议，作者随时可以突破模板新增幻想设定。
- 元配置变更不会静默删除或覆盖作者已有正文。
- 主设定编辑流程明显比 v2 简单。
