# 通用叙事设计与灵感工作面 v2 修订要求

## 本轮结论

v1 原型的视觉方向继续保留，但正式实现暴露出原型未覆盖的多对象、渐进规划和高频编辑问题。本轮必须修订原型交互合同，并与正式产品已经采用的“主画布 + 详情抽屉”布局一致。

## P0：故事弧必须支持多弧与阶段级选择

- 故事弧画布使用“一行一条故事弧、阶段为列”的矩阵，不能只演示单条人物弧。
- 每个阶段是可选择的剧情卡片，显示阶段名称、状态摘要、角色、结构位置和计划槽位。
- 点击阶段后，详情抽屉显示阶段自身及其关联叙事节点、线路、期待、计划关系和事实关系；不能退化为只选择整个故事弧。
- 故事弧必须能按角色筛选，筛选控件需要真实可操作。

## P0：章节计划与正文解耦

- 引入独立“章节槽位”作为排序和对齐轴；章节计划与正文章节分别可选关联到槽位。
- 覆盖“已规划待写”“计划与正文并存”“先写后补计划”三种有内容状态。
- 章节计划页提供计划、正文事实、对照三个视图；计划或正文不得静默覆盖另一方。
- 线路和故事弧的章节位置来自章节槽位，不再要求先存在正文。

## P1：结构上下文与详情阅读

- 左侧结构树选择必须过滤中间画布；提供清晰的“全部结构”返回入口。
- 详情抽屉默认是可扫描的阅读态，字段、来源、关联对象、计划/事实关系分组显示。
- 使用明确的“编辑”命令进入表单态，完成后返回阅读态；保留现有展开宽度能力。

## P1：页签顺序

按对象依赖和常用工作流排序：

```text
线路 -> 故事弧 -> 期待追踪 -> 章节计划 -> 验收 -> 自由大纲
```

自由大纲是可随时进入的发散区，但不再夹在结构化流程中间。

## P1：布局同步

- 不恢复 v1 的桌面常驻三栏。
- 桌面默认显示结构栏和宽主画布；选中对象后从右侧打开详情抽屉。
- 详情抽屉支持普通宽度与扩展编辑宽度，关闭后主画布恢复完整宽度。
- 移动端继续使用结构、内容、详情分步导航。

## 验收路径

1. 在故事弧页同时看到至少两条故事弧，按角色筛选后只保留相关弧。
2. 点击“丹成大道”阶段卡，详情展示该阶段、关联节点、两个期待及计划/事实关系。
3. 选择结构树中的章节组后，线路、故事弧、期待和章节计划均按该结构过滤。
4. 在章节计划页切换计划、正文事实、对照，能看到三种槽位状态。
5. 详情先以阅读态打开，点击编辑后才出现完整表单。
6. 页签顺序与本文件定义完全一致。
