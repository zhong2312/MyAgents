A · Recommended

纸上校样

最适合频繁、内联、窄宽度的 Agent 工具流。增删底色克制，代码文字保持正常对比。

B · Audit

双栏审阅

对复杂替换的 before/after 对照最强，但在聊天列里横向压力大，长行需要双重滚动。

C · Focus

终端聚焦

增删扫描速度最高，接近 CLI 心智；代价是从暖纸到黑底的材质跳变，不宜成为默认。

共同不变量

不是样式偏好
  1. 01元信息只出现一次：外层行管工具名，文件栏管路径与本文件统计。
  2. 02四列分离：旧行号 / 新行号 / 标记 / 代码，`+/-` 不再混进代码正文。
  3. 03颜色只辅助状态：代码保持可读，红绿落在底色、侧轨与 marker。
  4. 04长内容有预算：视口限高，需要时统一使用「展示全部」，不承诺新增复制能力。
